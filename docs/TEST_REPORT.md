## 评测目标

本项目需要交付一个能演示、能解释、能评测的小型英语学习 Agent。评测重点覆盖：

- Agent Loop：Observe、Think、Act、Answer 是否完整可见。
- 工具调用：词典、新闻推荐、作文评分、知识库检索是否能被触发。
- RAG：知识库是否能召回片段，并进入对话回答链路。
- 大模型接口：前端可配置 OpenAI-compatible URL、Key、模型名，作文和对话可使用当前配置。
- 失败案例：模型不可用、词库未命中、错误答案、长文章滚动等场景是否有兜底。

## 已记录的失败案例与优化

| 问题 | 处理 |
| --- | --- |
| 阅读悬停用在线 AI 太慢 | 改回本地快速词库与词形还原，保证 hover 响应流畅 |
| 单词模块曾因在线词库为空而空白 | 恢复本地 `local-fast` 词库作为首屏数据，后续可接在线扩展 |
| 作答后提示文字影响页面 | 删除“答对/答错”提示，改为单词卡平移和例句区出现 |
| 单词卡作答后布局跳动 | 固定上一题、下一题、选项区位置，只移动英文单词展示区 |
| 模型 API 不可用会影响演示 | 增加本地兜底逻辑，自动化测试也覆盖该失败场景 |

## 提示词和工具描述优化

- 对话系统提示词增加 RAG 片段注入，要求模型在相关时引用知识库内容。
- Agent Trace 明确展示 `RetrievalService`、`DictionaryTool`、`NewsRecommendTool` 等工具调用。
- 作文模块保留本地评分兜底，模型可用时再使用当前配置模型生成更完整批改报告。
- 阅读查词优先使用本地词库和词形还原，减少悬停等待时间。
