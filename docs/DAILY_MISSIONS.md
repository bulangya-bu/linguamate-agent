# 每日主题任务与成长证据

本轮只迭代电脑网页端，沿用绿蓝配色、纸感界面与低幅度插画动效。

## 学习路径

首页可以选择两个原创主题：「校园节水讲解」「迎新校园向导」。每个主题包含阅读、三个词语题、三轮情境表达和个人复盘。材料及校园地图均为虚构教学情境。

同一账号在北京时间同一天开启同一主题会续做原任务。跨日会创建新任务，历史原句与收获仍可在成长证据中查看。首页四阶段进度只读取当天所选主题的保存记录，不使用累计作文或阅读数来标记完成。

## AI 如何参与

情境反馈复用个人模型配置和 EnglishCoachService。请求包含角色、当前问题、阅读材料、已查看提示及主题词，返回原句对应的修改建议、短语与下一步练习。Observe / Think / Act / Answer 轨迹随回答保存。

提示分为词语线索、句式支架、示例表达；记录每轮作答时的提示等级。关键词核对仅显示词语是否出现，不判断语义、语法、流利度或学习者是否掌握。模型不可用时明确显示本地练习，保留原句和练习流程，不编造模型改写。

## 数据与接口

- `learning_mission_session` 保存账号、日期、内容快照、实际作答、提示、复盘和版本号。现有数据库通过 DatabaseMigration 自动建表。
- `/api/missions/today`、`/{key}/start`、`/sessions/{id}` 提供主题与续做。
- `/sessions/{id}/read|words|hint|turns|finish` 保存阶段行为；每次提交带版本号，防止旧窗口覆盖新记录。完成后保留只读证据。
- 主题词作答复用词汇进度与作答日志；错词进入强化队列，按计划到期后进入「待复习」。词库新增 `due` 范围，原 `review` 仍表示错词，保留 API 兼容性。
- `/api/report/growth` 返回近期词语作答、对话原句、实际作文提交与主题任务。写作的「我再次提交的改写」来自新一次原稿，AI 参考稿单独展示；仅相同来源、模型和评分标准允许分数比较。
- 草稿按账号、任务和轮次保存在浏览器，服务端确认保存后清除。刷新、失败重试保留输入；浏览器存储不可用时保留当前页输入。

## 展示入口

首页「开启今日主题」进入任务。完成后「打开成长证据」回看答案；学习档案的成长树支持点击和键盘 Enter 查看相应记录。词库将「待复习」与「错词」分开，统计与导航采用相同到期条件。

后台题库与成长图表继续使用现有组件。当前每日素材为两套精编主题，不声称每天自动生成新内容；后续扩展主题可以沿 MissionCatalog 添加，已开始任务保留内容快照。
